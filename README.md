## The joke

> "This meeting could have been an email, but then who would have watched me read that email out loud for 45 minutes?"

114 characters, one line, 22 words. The punchline reframes the meeting as a performance: nobody came to decide anything, they came to watch someone read the email out loud for three quarters of an hour. The meeting's only real job turns out to be the dramatic reading.

## How to run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (UTF-8, one line). The script checks the gate before writing: 1–200 characters, not blank, exactly one line.
